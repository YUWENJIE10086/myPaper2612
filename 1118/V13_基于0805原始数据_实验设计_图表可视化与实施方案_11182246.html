03｜Excel必须读出什么，才能真正开始实验？

这些是待核实的字段角色，不表示原xls里已经存在同名列。

目标标准字段含义读取或补充来源可能导致错误的问题模型用途
day真实记录日从宽表日列或长表日期解析日期错误、月底跨月、重复日期用于窗口、节令
sku_id品规编码/稳定规格名称同月表＋产品主数据同名不同码、改名、停售、缺乏编码作为图节点
qty业务实现量具体销量/购进量列，先核实单位不同表业务单位不一致、退货负值、累计/单日混淆预测目标
region地市/县区/营销部仅在源数据真正存在时使用单地区不可声称跨地市验证静态变量/分组
source_mask是否实测/明确零/缺失/停供源系统记录而非由qty=0推断真实0与无法采集混同缺失校验
sku_meta品牌/价位段/规格类别产品主数据，预测时刻可用映射更新需版本控制图先验/静态输入
known_future已公开且当时生效的计划信息、日期特征真实计划版本/节假日日历把事后计划作为未来已知输入＝泄漏TFT特征

输入表应该转换成的形式

date, sku_id, qty, unit, region(optional), observed_mask, sku_category(optional), known_future(optional) 2025-01-01, SKU_001, [原表真实值], [原表核验单位], ..., [可用标记], ... 2025-01-02, SKU_001, [原表真实值], ... ... [此处为字段结构样例，不含任何真实交易数值]

原始报表若为横向宽表（日期按列、品规按行），先逐日展开；若为长表，按日期＋SKU建立主键。重复键必须审查明细，不可直接求和。库存/投放计划不能自动等同销售量，也不能将预测时尚未公布的下一月计划作为已知未来变量。

核心数据准入指标

  1. SKU总数、每月新增/退出SKU数、品牌/价位段映射覆盖率（只在元数据存在时计算）。
  2. 原始可用日历日、每个SKU有效观测天数及90分位/50分位覆盖率；当日是否被采集与明确销售零值必须分开标记。
  3. 每月同一SKU是否代码稳定、计量单位是否跨文件变化、是否有累计量被错认成日度量。
  4. 源数据对月度汇总的可核验一致性——若分别记录购进和销量，不能当作同一个量简单相加核对。
  5. 预测期真实性：训练期只使用当时可以看到的数据，已发布的节日/日历可以使用，事后统计不可以。

05｜经典主干与只做一件事的创新

A. TFT主线

  1. 原模型保留变量选择网络、门控残差、时序注意力和多分位数损失，避免另起复杂网络。
  2. 确保过去观察变量（已实现销量）、静态变量（品牌/价位）与预测时可见的日历/计划明确分支；若没有历史正式计划，创新不能凭空围绕计划展开。
  3. 核心改进候选：已知协变量的发布时间掩码，或基于经过核实的品规→品牌加总层级一致性；两者必须经消融验证且最多主推一个。
  4. 强基线：季节朴素、LightGBM/CatBoost、TCN、原始TFT、已刊同业务研究可复现的部分。

B. 图网络主线

  1. 先复现原MTGNN（KDD2020）：端到端学习方向性品规图及时间卷积；Graph WaveNet为强对照。
  2. 如果业务产品主数据能提供品牌、价位段等弱先验，再开展GAT+TCN及业务先验图，不应直接因GAT知名度高就替代MTGNN。
  3. 仅在训练图网络不稳定或外推失败的事实得到证明后，设计“弱先验自适应图/边稳定性正则”机制，并让消融与随机图对照验证。
  4. 图边只能解释预测依赖。消费者迁移、缺货替代、违规套购、潜在需求需要完全不同的额外证据。

数学任务及证据指标

X_{t-L+1:t} ∈ R^(L×N×F) → Ŷ_{t+1:t+H} ∈ R^(H×N) H = 1, 7, 14；N 为经过日期与编码审计的SKU节点数。 MAE = mean(|Y - Ŷ|) wMAPE = sum(|Y - Ŷ|) / sum(|Y|) （分母为0时不定义） MASE = test_MAE / train_seasonal_naive_MAE TFT: quantile pinball loss(q ∈ {0.1,0.5,0.9}) 图关系: A = GraphLearn_θ(X_history); A不得使用任何未来值 稳定性: Jaccard(E_t,E_{t+1}) = |交集| / |并集|

08｜可视化版式原型：先定表达再填真实数据

下图是布局示意，刻意不绘制任何模型分数或虚构关系边；留白处应由真实程序输出填入。

期刊图片规范建议

  1. 所有科研图统一白底、蓝/青绿双主色、少量金色突出关注对象；不得用深色整屏科技背景或大面积发光。
  2. 字体统一宋体/黑体或中英文合适的论文字体，主图小图标签（a）（b）（c）与正文图注相符。
  3. 定稿输出可编辑SVG/PDF和300dpi PNG，不截Excel默认图直接贴稿；源数据保留CSV，绘图参数写入脚本。
  4. 坐标必须有单位和分母；误差图尽可能给95%CI，长尾组报告实际测试样本SKU数与天数。
  5. 邻接矩阵限制Top-20/30重要SKU，使用品牌/价位段分块、清晰分隔，避免100×100不可读的密集图；训练图而不是全期图。
  6. 典型案例图在训练前定义挑选原则，例如训练期销量分位25%、50%、90%附近各取一例，避免只展示最成功SKU。
  7. 同一图不宜既有销量又有准确率共用单轴；左右多面板优于双轴制造视觉错觉。

11｜最容易被期刊审稿人提出的六类硬伤

  1. 旧版.xls源数据未解码，不能给出SKU总数、行数、非零率或任何真实销量变化。
  2. 仓库历史方案曾出现用模型复制自制标签的高准确率逻辑风险。本研究必须使用真实后期销量，而不是用统计特征构造同源预测标签。
  3. 销量和购进量不是同一统计对象；供给受限时实现销量不等于潜在市场需求。
  4. 训练/验证/测试按日期冻结；图邻接矩阵不能用全体日期构造，也不能在测试期重复挑最优SKU解释。
  5. 若TFT与MTGNN没有显著优势，不能用图热力图或架构图替代预测效果证据。
  6. 真实数据与含业务敏感信息的明细图仅在授权环境处理；论文建议只披露匿名SKU或脱敏汇总。
综合决策规则：先做原始数据P0，再在同一可用信息集上比较CatBoost、原始TFT、原始MTGNN和Graph WaveNet；若图学习在不只一个测试月份/品规组有效且图边确有稳健证据，选择图协同预测，否则选TFT或更简单模型。论文的结论必须遵循实际实验结果，而不是反过来做图。
